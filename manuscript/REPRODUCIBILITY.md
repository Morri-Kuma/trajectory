# Reproducibility checklist — claim → source

Every quantitative claim in `benchmark_manuscript.tex` is traceable to a file under
`benchmark/reports/`, `benchmark/results/`, or `results/annotation_branch/`. This table
maps the headline numbers to their source and the script that regenerates them.

> **Single-seed vs multi-seed.** Every main results table is a **single-seed** (seed 42) point estimate read directly from a result file. The multi-seed 95% CIs (Fig 8) are a **derived** artifact backed by three forms of provenance: (i) all **90 seed-runs executed** — the run logs are in `logs/run_multiseed_benchmark.122804086.{1..90}.log` and record each per-seed output path; (ii) the exact inputs are **pinned by SHA-256** in `benchmark/reports/official_silver/multiseed_config_checksums.sha256`; (iii) the runs are **regenerable** with a documented HPC recipe (below). `multiseed_ci.csv` is the aggregated summary and `multiseed_manifest.csv` maps each run to its config sha256, output dir, and run log. The raw per-seed metric JSONs are not synced into the repo (size); the recipe below reproduces them. Leaderboards are labeled single-seed vs multi-seed accordingly.

> **Multi-seed rerun recipe (HPC).**
> ```bash
> python scripts/generate_multiseed_configs.py            # build the 90 seed configs (idempotent)
> sha256sum -c benchmark/reports/official_silver/multiseed_config_checksums.sha256   # verify inputs
> qsub jobs/shirokane/run_multiseed_benchmark_array.sh    # 90-task array -> per-seed metric JSONs
> python scripts/aggregate_multiseed_ci.py                # -> benchmark/reports/official_silver/multiseed_ci.csv
> python scripts/make_multiseed_figure.py                 # -> figures_v2/fig8_multiseed_robustness.png
> ```

## Compilation note

The benchmark workspace mount truncates reads of `benchmark_manuscript.tex` past ~27 KB,
so direct `pdflatex` on the mounted file stops mid-bibliography. The on-disk source is
complete (602 lines, ends with `\end{document}`); compile by copying the full file to a
local (non-mount) path first. The compiled PDF is 11 pages, 0 undefined references.
